# Marketing

Drafts, not finished copy. Read them, cut what does not sound like you, and
replace `[github link]` before posting anything.

- `reddit.md` — three posts for three subreddits, with prepared answers to the
  questions that always come.
- `youtube.md` — a five-minute script with a shot list and production notes.

Every number in both files comes from `mcai bench` and the test suite. If you
change the compiler, re-run it and update them — a wrong benchmark is the
fastest way to lose a technical audience.
